# 商品上架定价指南：从成本核算到促销底价

**资料核查日期：2026-10-14**  
**适用范围：** 面向电商新手的通用定价方法；平台部分以 TikTok Shop 马来西亚站为例。平台费率、活动规则及税务要求会变化，具体经营时以 Seller Center 当前页面、实际结算单及目标市场规定为准。本文用于经营测算，不构成税务或法律意见。

## 先说结论

上架价格不能只用“进货价加一点利润”决定。可靠的定价需要同时满足三件事：

1. **卖一单有正贡献：** 把采购、包装、履约、平台费用、达人佣金、优惠和退货损耗算进去。
2. **价格对市场有解释力：** 对比相同规格、数量、质量和配送条件的商品；若主张溢价，商品差异和消费者价值必须真实、可表达。
3. **促销后仍达到经营目标：** 先确定最低可接受成交价，再倒推出日常标价和活动折扣空间。

成本核算给出价格下限，不会自动证明顾客愿意支付该价格。成本底价高于市场可接受价格时，应重新谈供应成本、调整商品组合或放弃该 SKU，而不是靠虚假折扣掩盖亏损。

## 一、先区分价格、毛利和加价率

- **标价：** 商品页面展示的价格。它不一定等于卖家最终收到的钱。
- **实际成交价：** 订单中商品真实成交的价格。卖家券、平台券、活动补贴的承担方不同，最终结算影响也不同；要以订单结算明细为准。
- **毛利率：** `(售价 - 商品成本) ÷ 售价`。注意这里只是简化的商品毛利口径，未必包含平台、履约、广告等经营成本。
- **加价率（Markup）：** `(售价 - 成本) ÷ 成本`。

例如，成本 RM10、售价 RM15：加价率是 50%，毛利率是 33.3%。两者分母不同，不能把“加价 30%”当作“毛利率 30%”。

建议每个 SKU 同时看：**单件贡献利润、贡献利润率、月固定成本覆盖情况**，不要只盯商品毛利率或 GMV。

## 二、列全单件成本

先按“一件商品最终发到买家手上并完成一笔订单”核算。建议把成本分成三类：

| 成本类别 | 常见项目 | 计算注意点 |
|---|---|---|
| 商品与备货 | 采购价、打样、质检、国内集货、国际运输、关税/清关等适用费用 | 运费和税费按真实供货路线、商品和店铺身份判断，不要用别人的跨境成本套算 |
| 履约与售后 | 礼品包装、仓储、拣货打包、卖家承担的末端运费、破损/错发/退货退款预留 | 用自己承担的净成本；平台或买家承担的部分不要重复计入，也不要漏掉旺季包装升级成本 |
| 销售与平台 | 平台佣金、交易费、平台支持费、活动费用、达人佣金、广告、卖家承担的优惠、支付/汇兑费用 | 区分按比例收费和按单固定收费；确认费用计费基数，以及费用由谁承担 |

另列**月固定成本**，例如仓储租金、软件订阅、固定人力和会计费用。可用“月固定成本 ÷ 预计月成交件数”粗略分摊到单件；销量预测偏差会改变分摊结果，因此还要看总贡献能否覆盖实际固定成本。

### 单件贡献利润

通用口径可以写为：

```text
单件贡献利润 = 订单实际计入卖家的收入
             - 单件商品与履约成本
             - 平台及支付费用
             - 卖家承担的优惠、达人佣金和广告成本
             - 退货、退款、破损等预期损失
```

如果要看扣除固定成本后的单件经营利润，再从单件贡献利润中减去固定成本分摊。对平台优惠券、运费补贴或其他补贴，不要一概当作卖家收入或卖家成本；按结算单确认承担方和入账金额。

## 三、算出保本价和目标价

### 简化公式

以下公式适用于费率计费基数均可近似为成交价的场景。定义：

- `C`：每单随销量发生的成本，不含按成交价比例计收的费用。
- `F`：每单固定费用。
- `A`：每单分摊的固定经营成本。
- `r`：按成交价计收的费用率之和，例如适用的平台按比例收费；仅在这些费用基数相同或近似时才可合并。
- `m`：目标经营利润率，即扣除上述成本后希望保留的利润占成交价比例。
- `P`：卖家实际可用于该模型的成交价口径。

```text
覆盖单件成本的保本价（含固定成本分摊） = (C + F + A) ÷ (1 - r)
达到目标利润率的目标成交价             = (C + F + A) ÷ (1 - r - m)
```

若 `r + m ≥ 1`，模型无可行价格。若费用按不同金额计提、使用阶梯费率或平台补贴改变结算基数，不要把所有费率机械相加；逐项按 Seller Center 规则和订单结算口径计算。

**保本不等于值得卖：** 只覆盖变动成本的“贡献保本”没有覆盖租金、人力等固定成本。正式评估 SKU 时，要把目标销量和固定成本也放进判断。

### 示例：用假设数据演示

假设某固定内容礼盒：商品及头程成本 RM20、包装 RM2、卖家承担的履约成本 RM5、退货/破损预留 RM2、平均每单营销成本 RM3，因此 `C = RM32`；每单固定收费 `F = RM2`；月固定成本分摊 `A = RM4`。再**假设**可合并的成交价比例费用 `r = 18%`，目标经营利润率 `m = 15%`：

```text
含固定成本的保本价 = (32 + 2 + 4) ÷ (1 - 0.18) ≈ RM46.34
目标成交价         = (32 + 2 + 4) ÷ (1 - 0.18 - 0.15) ≈ RM56.72
```

这里的 18% 只是演算假设，不是 TikTok Shop 马来西亚费率，也不代表任一类目的实际费率。如果卖家准备提供 10% 自费折扣，且该折扣按成交价同比例降低，则初始标价至少约为 `RM56.72 ÷ (1 - 10%) = RM63.02`，才可能在折后达到该目标；最终仍需按券的承担方、费用计费基数及结算规则复算。

### 盈亏平衡销量

知道每件成交后能贡献多少，再估算一个月要卖多少件才能覆盖固定成本：

```text
保本销量 = 月固定成本 ÷ (单件售价 - 单件变动成本)
```

这里的单件变动成本应包含该单相关的费用；若平台费按售价比例计收，先从售价中扣除，再计算单件贡献。单件贡献小于或等于零时，销量越高不一定越接近盈利，应先调整价格或成本结构。

## 四、根据商品与市场选择定价方法

| 方法 | 适用情形 | 主要风险 |
|---|---|---|
| 成本加成 | 新品初次测算、成本数据较完整；用于建立底价 | 忽略需求和竞品，不代表市场会接受这个价格 |
| 竞品对标 | 同质化强、买家容易比较规格与价格 | 竞品可能在亏损促销，直接跟低价容易陷入价格战 |
| 价值定价 | 有可验证差异，如材料、设计、套装便利性、包装或售后服务 | “更好”“高端”等主观描述本身不能证明消费者愿意多付钱 |
| 组合/阶梯定价 | 商品有明确的不同数量或规格，如单件、双件装、礼盒 | SKU 内容、单位价格和选项必须清晰；不可把不相关商品伪装成低价变体引流 |

实际操作可以这样组合：**成本法定底线，竞品法检查价格区间，价值法决定在区间中的位置。** 若合理成本底线已高于买家可接受区间，优先换供应商、优化包装/物流、调整套装或停止该 SKU。

## 五、做一份可比的竞品价格调查

不要只看搜索结果中的最低数字。至少记录数个真实可比商品，并统一比较：

- 品类、品牌、材料、尺寸、数量、套装内含物、新旧状态；
- 买家最终付款价，而不是只看划线价或短期券前价格；
- 运费、配送速度、退货条件、评价和售后承诺；
- 价格观察日期、活动状态和适用的买家条件。

把同规格商品的当前价格看作参考区间，不当作“市场标准价”。低价竞品可能是引流款、清库存、规格更小或有平台补贴。若你的售价高于区间，应明确写出能被买家验证的差异；如果没有差异，就重新评估采购成本、规格和商品定位。

## 六、先设促销底价，再报名活动

上活动前分别算清：

1. 正常售价和实际成交价；
2. 卖家券、平台券、达人佣金、广告及活动费用分别由谁承担；
3. 活动后的单件贡献利润与贡献利润率；
4. 活动报名价、库存、履约和退货成本是否仍可承受。

如果卖家自费折扣率为 `d`，且没有其他费用基数变化，满足目标成交价 `P` 所需的折前标价至少为：

```text
折前标价 ≥ P ÷ (1 - d)
```

不要用虚构原价制造“大折扣”，也不要默认平台券完全由平台承担。若算出的活动成交价低于保本价，除非有明确、可量化且预算封顶的获客目的，否则不要报名；把亏损订单当作营销费用时，也要记录预算、目标和复盘期限。

## 七、TikTok Shop 马来西亚上架注意点

截至资料核查日，TikTok Shop 马来西亚 Seller Academy 的费用资料说明，佣金因商品子类目、Marketplace/Mall 卖家类型及是否参加 BXP 等而异；费用政策会更新。发布商品前应在后台核对自己店铺、类目、活动资格对应的当前费用，并用真实订单结算验证测算表，而不是沿用通用费率或其他卖家的截图。

平台商品刊登指引还要求：

- 商品页、图片、视频、价格、折扣和实物保持一致；不得使用夸张促销价、无依据的价格比较或误导性定价引流。
- 商品标题描述商品本身，不在标题中塞促销信息；规格/变体需对应真实商品，不要把差异很大的不同商品、单品与套装混在同一个 listing 里吸引低价点击。
- 清楚写明套装内容、数量、规格和不同选项的差异；买家应能据此判断实际会收到什么。
- 商品价格主张和促销信息应真实、可核实，并遵守目标市场适用法律和当前平台规则。

促销规则和费率可能变更。报名活动或改价前，再查 Seller Center 的最新条款及订单结算明细；遇到目标市场法律适用问题，应向当地合规/税务专业人士确认。

## 八、新品定价实操清单

- [ ] 确定 SKU 的准确类目、规格、数量、套装清单和目标买家。
- [ ] 收集采购、运输入仓、包装、仓储、履约、售后等成本凭据。
- [ ] 从 Seller Center 查当前适用的平台费率、固定收费、活动规则和计费基数。
- [ ] 将达人佣金、广告、卖家承担优惠、退货/破损预留纳入单件测算。
- [ ] 算贡献利润、保本成交价、目标成交价和可接受的活动底价。
- [ ] 调研同规格竞品的实际成交价，记录日期、运费和促销条件。
- [ ] 检查日常标价与折后价是否真实，页面价格、图片、SKU 和实物是否一致。
- [ ] 上架后按实际结算复盘：每单贡献、成交转化、优惠消耗、退款退货、库存与现金流；不要只用 GMV 判断定价成败。

### 配套 JavaScript 计算脚本

可使用[马来西亚 TikTok Shop 定价计算脚本](2026-10-14_TikTokShop马来西亚定价计算.js)：采购价和运费以人民币（CNY）输入，重量以**包裹计费重量（kg，含包装；有体积重时输入计费重）**输入；采购成本和运费按配置汇率折算。脚本的**建议上架价、成本折算、费用金额和利润金额统一以马来西亚令吉（MYR / RM）输出**；其他单件成本以 RM 输入。脚本按用户提供的运费参考图估算：≤0.5kg 采用 CNY 15–30；0.5–1kg 在图中 0.5kg 与 1kg 两个区间间线性插值（粗估）；>1kg 要输入实际物流报价。≤1kg 可输入本商品实际净运费区间覆盖估算；系统按运费区间高值计算保守上架价，同时输出低/高运费情景下的利润。未设置时还会询问其他单件成本和 Seller Center 实际平台/支付比例费用。

脚本使用的保守价格公式为：`上架价（RM）= 向上进位[(采购价（CNY）×汇率 + 运费高值（CNY）×汇率 + 其他单件成本（RM）+ 每单固定费（RM）) ÷ (1 - 平台比例费率 - 达人/广告费率 - 20%) ÷ (1 - 卖家折扣率)]`。20% 指**折后成交价口径的单件贡献利润率**，不是加价率；所有比例费暂按折后成交价计提，需用实际结算单核对计费基数。

运费参考图给出的数值只是估算，实际运费受重量、尺寸、体积重、货物属性和活动补贴影响；有真实物流报价时应优先使用真实值。人民币汇率、平台费用、额外成本、达人佣金和卖家折扣均须按实际情况更新；脚本结果是成本底价模型，仍需与同规格竞品实际成交价比较。
